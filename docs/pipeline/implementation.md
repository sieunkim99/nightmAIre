# 생성 파이프라인 v3 · 실제 반영 범위

2026-11-17 · 비교 기준 `5a03113` · 대상 브랜치 `sieun`.

[설명 문서](index.html)는 설계 의도와 예시를, 이 문서는 구현 여부와 한계를 설명한다. 최종 결과 형식 등 [결정 목록](decisions.md)의 선택은 아직 확정하지 않았다.

## 무엇을 바꾸었는가

| 기준 구현 | 이번 구현 | 남은 검토 |
|---|---|---|
| writer 한 번이 덱·위험·서사를 결정 | 근거 연결 → 미래 후보 → 선택 → 꿈 → 검토 분리 | 호출별 실제 품질·대기·비용 |
| 기존 6개 덱 / HTML 16개 혼합 개념 | YAIR 14개 분류, 별도 출처·주장·기제 3종 | 16장 전체 문헌 재검토·기제 확장 |
| 위험에 맞춘 한 미래 | 다른 가정, 행위자, 파급 차수·시간, 연결 이유 | 후보의 의미상 다양성 |
| 다이얼·소품 | 세계 1–3개 선택, 위임, 새 가정, 사물, 제외 요청 | 대화 자연스러움·아이 이해도 |
| 고정 6장면·하나의 규칙 | 세계별 규칙과 전환, 가변 장면·읽기 경로 | 서사 난도와 길이 예산 |
| 그림을 전부 기다림 | 텍스트 먼저, 그림 별도 요청·누락 재시도 | 이미지 출력 후 의미·연령 검토 |
| 실패하면 데모 대체 | 오류·재시도, 데모 명시 | 실제 제공자 오류·지연 조건 |
| 성찰·되돌리기로 이동 | 읽고 종료 / 세계·쪽지 바꾸기 | 성찰은 이후 범위 |

## 실행 단계와 계약

1. **SeedRecord** — 경험/상상/예시, 확인한 원문, 입력별 ID, 비어 있는 항목. 3개의 짧은 질문과 수정 화면을 제공한다. 감정·행동을 자동으로 채우지 않는다. 완전한 자유 대화형 인터뷰는 아직 아니다.
2. **GroundingBundle** — 등록된 기제 ID만 선택한다. 적용 조건이 관찰되는지, 불명확한지, 미래 가정에서만 해당하는지 구분한다. 조건을 한 번 확인하거나 다른 재료로 바꾼다. 원문 ID와 적용 한계를 남긴다.
3. **FutureGraph** — 약 3개 후보를 요청한다(2–6 범위). 가정·사건·행위자·파급 차수·시간·결과 종류, 연결 이유·주장 ID·가정 ID를 기록한다. 관계 종류는 `hypothesis`, `association`, `moderation`이며 확정적 인과로 승격하지 않는다.
4. **ChildSelection** — 1–3개 후보, 선택 위임 여부, 새 가정 쪽지, 사물, 강도를 받는다. 쪽지가 있으면 **선택한 미래부터 수정하는 별도 호출**을 한다. 후보 ID를 보존하고 아이의 가정은 `origin: child`로 표시하며 연결에서 참조한다. 수정 전후 그래프를 모두 남긴다.
5. **DreamBlueprint + Story** — 한 호출이 두 산출물을 만든다. 세계별 규칙, 후보 참조, 장면별 사건 참조, 연출 전환, 연결 사물, 읽기 순서, 아이 기여 설명을 포함한다. 설계의 ⑤와 ⑥ 집필을 별개 호출로 강제하지는 않는다.
6. **검토** — 코드로 참조·구조를 검사하고 별도 모델 호출로 입력 충실도·근거 범위·선택 반영·연결감·연령 적합성·제외 요청을 검토한다. 의미 검토 실패는 한 번 재집필한다. 재실패나 구조 오류는 오류를 반환한다.
7. **읽기·그림** — 검토된 텍스트를 먼저 반환한다. 이미지는 첫 장면을 참고로 나머지를 최대 2개 동시 생성하며, 성공한 파일은 재시도에서 보존한다. 읽고 나오거나 선택을 바꾼다. 되돌리기·성찰 과제를 요구하지 않는다.

기본 라이브 텍스트 호출 수는 **4회**(근거·미래·집필·검토), 새 쪽지가 있으면 **5회**, 의미 검토 실패로 수정하면 **2회 추가**다. 확인 질문은 별도 요청으로 근거 연결을 다시 수행한다. 20장면은 자원 상한이며 권장 장면 수가 아니다.

## API와 보존

| 요청 | 입력 | 출력 |
|---|---|---|
| `POST /api/prepare` | 확인한 재료, 불명확한 조건 유지 여부 | 질문 / 재료 변경 / 임시 ID와 세계 씨앗 |
| `POST /api/dream` | 임시 ID, 세계·쪽지·사물·강도 | 장면·설계·근거 이력, 꿈 ID, 그림 상태 |
| `POST /api/dream/:id/images` | 꿈 ID | 장면별 파일, 완료/일부 실패 |
| `POST /api/discard` | 준비 ID·꿈 ID | 메모리 참조 삭제 |
| `GET /api/library` | 접속 코드(설정된 경우) | 버전·분류·기제·주장·출처 |

ID는 무작위이며 서버 메모리는 최대 200건, 30분 만료, 최대 1분 간격 정리다. 새로고침 시 입력·이야기를 복원하지 않는다. 종료는 진행 요청을 중단하고 기억한 ID를 폐기한다. 비정상 연결 종료 중 생성 완료 등 경계 상황은 만료 정책이 최종 정리를 맡는다.

원문·이야기를 연구 로그에 기록하지 않는다. 선택적 메타데이터만 남길 수 있다. **이미지 파일은 이 메모리 삭제에 포함되지 않는다.** 이미지 자동 삭제, 인증된 이미지 전달, 모델 제공자의 보존 정책, 실제 참여자의 동의·자료 접근은 운영 전에 별도로 정한다.

## 연구 근거의 실제 연결 범위

YAIR Table 3의 14개 중간 분류는 검색·범위 확인용 레지스트리다. 그림 설명 15개, 이전 스냅샷 13개와 차이를 기록했다. 14개 모두가 생성 가능한 경로라는 뜻은 아니다.

첫 구현 기제는 세 가지다. 고등학교 수학 지원 방식 연구에 기대어 독립적 시도 대체를 **조건부 해석**하고, YAIR 사례 분류에서 미검증 수용을 **사례 기반 가설**로, 성인 관계 연구에서 관계 활동 대체를 **인접 근거에 기댄 가설**로 둔다. 출처·주장·조건·반대 조건·연령/기간/과제 차이를 함께 전달한다. 맞지 않는 입력은 억지로 세 기제에 끼워 넣지 않도록 지시한다.

기존 16개 카드의 분류·기제·시스템 사건·결과 재배치 방안은 [taxonomy.md](taxonomy.md)에 있다. 기존 파일은 비교용으로 보존했고 미검토 내용을 검토 완료로 표시하지 않았다. MIT Risk Repository 보조 축은 문서 설계에 포함되어 있으나 실행 스키마의 필수 필드로 연결하지 않았다.

## 검사와 한계

- 자동 검사 **15개 통과**, Vite 빌드 성공. 원문 종류·미확인 항목, 출처와 사건 참조, 연결이 끊긴 미래, 선택 보존, 새 가정이 writer 이전에 반영되는지, 검토 재시도, 실패의 데모 대체 방지, 만료·삭제, HTTP 계약, 가변 장면 변환.
- 데모는 세계 1/2/3개 선택에 따라 3/4/5개 장면을 만든다. 가변 길이 확인이며 실제 모델 품질 평가가 아니다.
- 브라우저에서 1개/2개 세계의 3장면/4장면 읽기, 명확한 종료, 352px 화면의 가로 넘침 없음, 문서의 단계 전환·결정 13항목 저장·복원·Markdown 내려받기를 확인했다. 문서 저장 테스트의 선택은 미정으로 되돌렸다.
- 실제 모델의 서사·후보 다양성·입력 충실도·전이 한계 평가와 아동 단독 체험 연구는 수행하지 않았다. 기존 `eval/` 결과를 새 파이프라인에 전용하지 않는다.
- 검토는 같은 기반 모델의 별도 호출이다. 독립 연구자 검토나 과학적 검증을 대체하지 않는다. 후보 미리보기와 그림 출력에 대한 별도 의미 검토 단계는 아직 없다.
- 이미지 프롬프트에 세계 규칙·제외 요청을 전달하지만, 나온 그림의 내용·일관성을 자동 확인하지 않는다. 중단 시 이미 생성된 파일의 회수·삭제도 추가 작업이다.
- 안전 장치 관련 위험은 분류에서 지우지 않았다. 생생한 현실 위기·연령 부적합한 재료를 악몽으로 확대하지 않는 전환 지시를 넣었지만 모든 사례의 판별 정확도를 검증하지 않았다.

## 우선순위

**P0 — 실제 아동 체험 전:** 문헌 주장과 기제 대응을 연구자가 검토하고, 실제 모델 출력·민감한 입력 처리·단독 종료를 확인한다. 원문·그림 보존과 삭제, 접근, 동의 기준을 정한다.

**P1 — 설계 비교:** 한 편/갈림길/지도, 두 세계/세 세계, 쪽지 기여 이해도, 읽기 길이와 대기를 비교한다. 나머지 카드 경로는 근거 검토 순서에 따라 추가한다.

**P2 — 운영:** 필요한 데이터 형태를 정한 뒤 저장소와 호스팅을 선택한다. Supabase 이전·Render/Vercel 선택·약관 검토·실서비스 배포는 이번 변경에서 하지 않았다.
