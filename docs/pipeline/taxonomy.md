# 위험 분류와 메커니즘을 분리하는 방법

2026-11-17 확인. 분류 전체의 수록과 생성용 메커니즘의 문헌 검토 완료는 서로 다른 상태다.

## 사용할 출처와 버전

청소년 상호작용의 주 분류는 **Yu et al., SOUPS 2025 정식 논문**의 Table 3, 경로는 Table 1에 맞춘다. [USENIX 원문](https://www.usenix.org/system/files/soups2025-yu.pdf).

이전 설계의 ‘YAIR 13개 전부’는 버전 정보를 빠뜨린 표현이었다. 기존 arXiv/HTML 대응과 달리 정식 PDF의 Table 3에는 **14개**의 중간 항목이 보이며, Figure 1 설명은 **15개**라고 적혀 있다. 이 불일치를 임의로 메우지 않는다. 아래 표는 Table 3에 실제로 열거된 항목을 기준으로 한 스냅샷이며, 84개 세부 항목을 모두 재현하거나 검증했다는 뜻이 아니다.

| 프로젝트 ID | 상위 영역 | 중간 항목의 한국어 대응 | 생성에서의 처리 관점 |
|---|---|---|---|

| bias.stereotypes | 편향·차별 | 암묵적 편향·고정관념 | 누가 다르게 대우받는지, 시스템·제도 조건 포함 |

| privacy.system | 개인정보 | 시스템에서 발생하는 개인정보 위험 | 수집·저장·모델·접근 권한 등 시스템 책임 포함 |

| development.behavior | 행동·사회 발달 | 유해 행동에 대한 영향 | 위해 행동을 구체적 실행 시나리오로 만들지 않음 |
| development.boundary | 행동·사회 발달 | AI가 시작하는 동의·경계 침해 | 사용자 의도 없이 시작된 AI 행동도 원인으로 기록 |
| development.social | 행동·사회 발달 | 사회·정서 발달 위험 | 실제 사람과의 활동을 대체하는지·보완하는지 구분 |

한국어 명칭과 생성 처리 관점은 프로젝트의 번역·설계 판단이다. 공식 정의와 동일한 것으로 인용하지 않는다. 이 항목들이 개인의 위험 점수나 발생 확률은 아니다.

네 경로는 상호 강화, AI가 매개하는 자기 자신에 대한 위해, 다른 사람에 대한 위해, 사용자의 위해 의도 없이 시스템에서 시작하는 위해로 구분한다. 하나의 위험 영역이 여러 경로에 속할 수 있다. 아이의 습관만을 원인으로 고정하지 않는다.

## 보조 축: MIT AI Risk Repository

[MIT AI Risk Repository](https://airisk.mit.edu/risks)는 위험의 **영역**과 **발생 주체·의도·시점**을 구분한다. 여기서는 시스템과 다른 사람, 기관의 선택을 빠뜨리지 않게 하는 보조 축으로 사용한다. 메타 리뷰에 기반한 분류를 개별 인과관계의 실험적 검증으로 취급하지 않는다. 2026-11-17 확인한 사이트는 7개 영역·24개 하위 영역을 사용하므로 예전 버전의 23개 표기와 구분한다.

프로젝트의 추가 필드는 `actors`, `interaction`, `context`, `conditions`, `mediator`, `possibleOutcomes`, `counterConditions`, `supportingClaimIds`, `opposingClaimIds`, `limits`다. 이 필드 구조는 YAIR 또는 MIT 분류를 그대로 옮긴 것이 아니라 실제 생성에 필요한 프로젝트 설계다.

## 근거 레코드의 최소 단위

출처 전체가 아니라 **하나의 주장**을 연결한다. 각 주장에는 연구 설계, 대상, 과제·환경, 기간, 결과, 적용 한계, 원문 위치, 검토 상태를 기록한다. 관계는 `supports`, `opposes`, `context`로 구분한다.

기제의 인과적 설명이 논문에서 직접 검증되지 않았다면 `interpretation`으로 기록한다. 새로운 제도·시간·사회적 파급은 `assumption`, 꿈의 초현실적 사건은 `metaphor`다. 숫자 확률을 임의로 붙이지 않는다.

## 첫 실행 범위와 연구 검토

첫 코드에서는 학습 기회 대체, 검증 없는 정보 수용, 실제 관계 활동의 대체라는 작은 범위를 끝까지 연결한다. 이는 이 세 기제가 모두 초등학생에게 인과적으로 검증되었다는 뜻이 아니다. 기제마다 연구의 대상·설계 차이와 제한을 출력에 보존하고, 해당 조건이 없으면 현재 아이의 문제가 아닌 명시된 미래 가정에서만 사용한다.

- 학습: [Bastani et al., PNAS 2025](https://www.pnas.org/doi/10.1073/pnas.2422633122). 고등학교 수학의 지원 방식 비교. 초등 장기 발달을 입증하지 않음.
- 정보 수용: YAIR의 비의도적 오용 사례·분류를 맥락 근거로 사용. 수용 행동이 현재 입력에 없으면 추정하지 않음. 구체적 확률·장기 효과는 주장하지 않음.
- 관계: [Fang et al., 2025 v2](https://arxiv.org/html/2503.17473v2). 성인 대상 4주 연구. 실제 사용량과 결과의 연관은 사용량의 무작위 배정 효과가 아니며, 개인적 대화·친밀감 자체가 항상 해롭다는 결론도 아님.

기존 16장의 출처는 별도로 이 구조에 옮겨 검토한다. 새 14항목 레지스트리와 3개 실행 기제, 옛 16개 카드가 각각 무엇을 세는지 문서·화면에서 구분한다.
